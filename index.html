NexoVerde IA

Esta página contiene la Política de Privacidad, las Condiciones de Uso y las instrucciones para solicitar la eliminación de datos relacionados con NexoVerde IA.

Última actualización: septiembre de 2026

Política de Privacidad

NexoVerde IA es una aplicación desarrollada para permitir la realización de consultas mediante WhatsApp y generar respuestas relacionadas con información autorizada del sistema.

Cuando un usuario envía un mensaje a NexoVerde IA, la aplicación puede procesar el número asociado a la conversación, el contenido del mensaje y la información necesaria para generar una respuesta.

La aplicación utiliza servicios tecnológicos de terceros, incluyendo la Plataforma de WhatsApp Business de Meta y servicios de inteligencia artificial, para recibir mensajes, procesar consultas y generar respuestas.

Solo se envía a los servicios de inteligencia artificial la información que el sistema determine necesaria y autorizada para responder la consulta correspondiente.

NexoVerde IA no utiliza los datos obtenidos mediante WhatsApp para publicidad ni para la venta de información personal.

La información es tratada únicamente con la finalidad de proporcionar las funciones de consulta y respuesta de la aplicación.

Condiciones de Uso

NexoVerde IA se proporciona como una herramienta de consulta y asistencia informativa.

Las respuestas generadas automáticamente pueden contener errores, por lo que la información importante debe ser verificada antes de ser utilizada para tomar decisiones oficiales o administrativas.

Los usuarios se comprometen a utilizar el servicio únicamente para fines autorizados y legítimos.

Eliminación de Datos

Los usuarios pueden solicitar la eliminación de los datos asociados a sus interacciones con NexoVerde IA.

Para realizar una solicitud de eliminación, envía un correo electrónico a la dirección de contacto registrada para la aplicación indicando que deseas solicitar la eliminación de tus datos relacionados con NexoVerde IA.

La solicitud será revisada y se eliminarán los datos que correspondan cuando resulte aplicable.

Contacto

Para consultas relacionadas con privacidad, tratamiento de datos o eliminación de información, utiliza el correo electrónico de contacto oficial registrado para NexoVerde IA.
